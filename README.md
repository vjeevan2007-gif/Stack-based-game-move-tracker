# Stack-based-game-move-tracker
Ever wondered how games track your moves? Today we’re using the Stack data structure to build a Move Tracker! 🚀 ​By using the LIFO (Last-In, First-Out) principle, we can easily "Pop" moves to undo them and "Push" them onto a second stack to redo. Simple, efficient, and O(1) time complexity! ​
